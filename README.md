# Mihiret's Birthday Website 💕

A romantic, interactive birthday website created with love for Mihiret.

## Features

- 🎨 Beautiful romantic design with pink and rose color palette
- 💕 Falling heart animations throughout the site
- 📸 Interactive photo gallery with your memories together
- 💌 Heartfelt love letter section
- 🎁 Secret surprise message to unlock
- ✨ Smooth animations and transitions
- 📱 Fully responsive design

## Tech Stack

- React 18
- Vite
- Tailwind CSS v4
- Motion (Framer Motion)
- TypeScript

## Development

```bash
# Install dependencies
pnpm install

# Run development server
pnpm dev

# Build for production
pnpm build
```
